# Room8 心寓官方網站

純靜態網站（一個 `index.html` 加圖片），放在 Vercel，推上 GitHub 後約 1 分鐘自動更新。

## 檔案
- `index.html`：整個網站（文字、清單、表單、樣式都在這裡）
- `photos/`：首頁滾動照片（3:2，1200×800）
- `logo-h.png`、`favicon.png`、`apple-touch-icon.png`：logo 與網站小圖示

## 常改的地方（都在 index.html 的 `<script>` 裡）
- `ALL_LISTS`：資訊清單。加 `off:true` 可暫時隱藏。
- `LINES`：三個 LINE 官方帳號連結
- `SOCIAL`：FB、IG、YouTube 連結
- `PHOTOS`：首頁照片清單
- `COMPANY`：頁尾公司資訊
